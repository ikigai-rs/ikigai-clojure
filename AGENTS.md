# AGENTS.md

`ikigai-clojure` is a Clojure client and servable peer for the ikigai wire protocol, for
babashka and the JVM.

- Read [ROADMAP.md](ROADMAP.md) for the order the face is built in, and
  [test/vectors/README.md](test/vectors/README.md) before touching a vector: they are
  verbatim copies, never edited by hand.
- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read:
  error messages and terminal text.
- Run `bb lint`, `bb test` and `clojure -X:test` (what CI runs) before opening a pull
  request.
- Security reports go through
  [private vulnerability reporting](https://github.com/ikigai-rs/ikigai-clojure/security/advisories/new),
  never a public issue.
- Write American spelling (behavior, color, labeled).
